# Tela de Login Responsiva 💻📱

Bem-vindo(a) ao repositório do projeto **Tela de Login**!

Este é um mini projeto desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos em programação Front-end. O foco principal deste trabalho foi criar uma interface de usuário atraente e 100% responsiva, adaptando-se perfeitamente a diferentes tamanhos de tela (Mobile, Tablet e Desktop).

## 🎯 Objetivo do Projeto

Este projeto foi construído para desenvolver e aprimorar as seguintes habilidades:

- **Mobile-First:** Aplicação do conceito de desenvolver primeiramente para telas menores.
- **Media Queries:** Uso prático de `@media` no CSS para adaptar o layout em tablets (768px a 992px) e desktops (acima de 992px).
- **Posicionamento CSS:** Utilização de `position: absolute` e `transform: translate` para centralização de elementos.
- **Variáveis CSS:** Implementação de Custom Properties (`:root`) para padronização e fácil manutenção da paleta de cores.
- **Ícones do Google:** Integração com o _Google Material Symbols_ para enriquecer visualmente os campos de formulário.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização da página, transições (`transition`), variáveis de cor e media queries para responsividade.

## 📂 Estrutura de Arquivos

- `index.html`: Estrutura principal da página de login.
- `estilos/style.css`: Estilos globais e configurações para a versão mobile.
- `estilos/media-queries.css`: Regras de adaptação do layout para tablets e desktops (alterando o uso de `float` e larguras da caixa de login).
